# MimicMSK Models

This repository contains the main MimicMSK model packages for OpenSim and MuJoCo.

## OpenSim

- Main model: `MimicMSK_Model_opensim/MimicMSK_OpenSim.osim`
- Geometry assets: `MimicMSK_Model_opensim/Geometry/`
- Notes: `MimicMSK_Model_opensim/README.md`

## MuJoCo

- Full-body model: `MimicMSK_Model_mujoco/body/myofullbody.xml`
- Scene model: `MimicMSK_Model_mujoco/scene/musclemimic_scene.xml`
- Meshes and assets are included under `MimicMSK_Model_mujoco/`.
